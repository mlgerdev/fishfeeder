Flash the firmware straight from your browser — no toolchain needed.

UI NODE

ESP32-S3-Touch-LCD-4.3B

The 4.3" touchscreen panel: LVGL home screen, feeding schedule, feed history and the ESP-NOW link to the relay node.

RELAY NODE

ESP8266 NodeMCU V3 + 5V relay

The actuator node: listens on ESP-NOW and pulses the feeder relay. Read the RELAY MAC from the serial monitor after flashing.

Before you flash: connect the board with a USB cable and use Chrome / Edge / Opera (desktop or Android) — Web Serial is required. A first install erases the device, so WiFi credentials are set afterwards via secrets.h (see the README). If flashing the ESP32-S3 fails, hold the BOOT button while pressing RESET, then retry.
